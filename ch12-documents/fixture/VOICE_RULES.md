# Voice rules for Counting TODOs (G03 draft)

- US English.
- Second person for instruction ("you run", "you pass").
- ASCII only: use `'` `"` `--` `-` `...` `(c)` `(R)` `x`. No smart quotes, em dashes, or emoji.
- No hype. Banned phrases: "delve", "unleash", "game-changer", "in today's fast-paced world", "it's important to note", "in conclusion", "thrilled to announce".
- Do not invent author biography, awards, employers, benchmarks, user quotes, or version numbers.
- Allowed placeholders only if the outline names them. For G03: none. Write concrete text.
- Prefer short sentences. Prefer concrete commands over slogans.
- Headings in the draft must match the outline section titles exactly when the prompt lists them.
