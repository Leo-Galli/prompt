# Exercise 1 -- Mini-spec for a weekend tool

Write a `MINI_SPEC.md` for a tool you could finish in a weekend (not todocount).

Include at least:

1. Identity (name, goal, language)
2. Behavior (3-5 bullets)
3. Non-goals (at least two)
4. A task map table with ids T01-T05 and a "Done when" column
5. Session rules that say the spec is source of truth and chat is not a plan

Constraints:

- ASCII only
- No invented benchmark numbers
- Keep the whole file under ~80 lines

Done when: a stranger could pick T01 and know what "done" means without asking you.
