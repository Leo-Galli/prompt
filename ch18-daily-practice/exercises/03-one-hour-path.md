# Exercise 3 -- Write a personal one-hour path for a teammate

## Done when

- You name exactly three chapters (default: Chapter 2, Chapter 9, Chapter 11 unless you justify swaps)
- You name exactly one shared template path under `templates/`
- You name exactly one companion folder URL or path
- The whole note is <= 120 words
- ASCII only; no emoji; no invented benchmark claims

## Steps

1. Assume the teammate has sixty minutes and a terminal.
2. Write the path as a short note they can paste into chat or email.
3. Prefer the book's front-matter one-hour trio unless their job is narrowly media-only or eval-only -- then justify the swap in one sentence.
4. Point at `templates/daily-card.md` (or `single-task.md` / `fix-pass.md` if that matches the trio).
5. Point at one companion folder, not the whole repo dump.

## Notes

A thirty-link reading list fails this exercise. Cruel brevity is the point.
