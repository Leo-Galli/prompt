# Exercise 1 -- Fill the daily card for a week

## Done when

- You have seven dated fills (or five workdays) using `templates/daily-card.md` or a local copy
- Each fill names exactly one job
- Each fill has a matching dated raw output file
- `python -m prompt_lint` exits 0 on each filled card you ran

## Steps

1. Copy `templates/daily-card.md` to a personal log folder if you do not want to edit the shared file.
2. Each day: fill date, tool, job, seven parts, lint command, and save path.
3. Run prompt-lint until exit 0.
4. Run the ask once. Save the raw reply with a dated filename.
5. Do not invent a personal "percent better" score.

## Notes

If you miss a day, leave a gap. Do not backfill fake cards.
