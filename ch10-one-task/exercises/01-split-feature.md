# Exercise 1 -- Split a feature into session-sized tasks

Pick a feature you want built this week (CLI flag, docs page, small API endpoint, or similar).

Write five session-sized task lines. Each line must:

1. Have a stable id (`T01` ... `T05` or your own scheme)
2. Name one primary outcome
3. Fit in one focused sitting (roughly under two hours of agent+human verify time)
4. Avoid bundling docs + code + CI + "nice to have" in the same id

Done when: you have five ids, and none of them requires finishing another id first inside the same session (dependencies are fine across sessions).
