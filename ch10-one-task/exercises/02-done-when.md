# Exercise 2 -- Write done-when for each task

Take the five ids from Exercise 1.

For each id, write one "done when" line a stranger could grade. Prefer:

- A command that must pass
- A file or flag that must exist
- A behavior you can demo without guessing

Reject vibes: "improve", "polish", "make nicer", "almost done."

Done when: all five ids have observable done-when lines, and you can point at the verify step for each.
