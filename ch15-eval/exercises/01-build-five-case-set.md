# Exercise 1 -- Build a 5-case set

Goal: Create five golden inputs for one template you own (or reuse `template/label-severity.md`).

Done when:
- You have five short input notes in a `cases/` folder (or a dated scratch folder)
- Each case has an `expected_label` a stranger could defend from a written rubric
- At least two labels differ (do not make five identical LOWs)
- ASCII only; no invented product metrics inside the notes

Steps:
1. Write a one-paragraph rubric for your labels (or copy the HIGH/MED/LOW meanings from the restored prompt).
2. Draft five issue notes that cover different rubric classes.
3. Record expected labels next to each note.
4. Optional: add an `EXPECTED.json` with `id`, `input_file`, and `expected_label`.

Stop when a teammate can grade a model reply without asking you what "serious" means.
