## What this does

`linecount` is a command-line tool that counts non-blank lines in one or more text files. It is aimed at developers who already work in a terminal and install Python packages with pip.

## Install

```bash
pip install linecount
```

## Usage

```bash
linecount path/to/file.txt
```

```text
path/to/file.txt: 42 non-blank lines
```
